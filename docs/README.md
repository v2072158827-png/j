# 项目文档管理

本文件夹用于跟踪简历优化工具项目的所有改动、决策和遗留问题。

## 文件说明

| 文件 | 用途 |
|------|------|
| `TASKS.md` | 任务跟踪，按时间记录每个任务的详细信息 |
| `CHANGELOG.md` | 修改记录，列出所有文件改动及原因 |
| `DECISIONS.md` | 技术决策记录，记录关键选型理由 |
| `ISSUES.md` | 遗留问题，记录待处理事项 |

## 使用规则

1. **每次完成任务后**，必须更新这些文档
2. **TASKS.md** 按任务记录，包含：
   - 任务概述（目标、状态）
   - 修改记录（改动文件及原因）
   - 修改对比（关键代码变化）
   - 测试记录（方式、结果）
   - 决策记录（如有）
   - 遗留问题（如有）
3. **CHANGELOG.md** 记录所有文件级别的改动
4. **DECISIONS.md** 记录重要技术选型
5. **ISSUES.md** 记录待处理事项，解决后打勾

## 状态标记

- ✅ 完成
- ⚠️ 进行中 / 有风险
- ❌ 失败 / 阻塞
